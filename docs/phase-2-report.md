# تقرير المرحلة 2 — اتصال ميتا والويب هوك (Meta OAuth + Page Discovery + Webhook Receiver)

**التاريخ:** 2026-10-22
**الحالة:** التنفيذ الآلي مكتمل — بانتظار الأدلة الحية للمالك لإغلاق Gate G2
**النطاق:** إعداد تطبيق ميتا، OAuth (state + PKCE)، اكتشاف الصفحات/إنستغرام، تشفير الرموز، صحة الاتصال، استقبال الويب هوك (HMAC + تحيّن + تكرار)، واجهة «الاتصالات»

---

## 17.1 الحالة

المرحلة 2 (من §4.2–§5.2 و§7.1 و§9 في تقرير المرحلة 0) منفّذة بالكامل: موديول `meta` في الـ API (12 مسارًا جديدًا)، خمس جداول جديدة، تشفير AES-256-GCM للرموز عند الراحة، استقبال تحيّن/أحداث الويب هوك بتوقيع HMAC-SHA256، وصفحة «الاتصالات» الحقيقية في الواجهة (لم تعد حاوية). **لم يُبنَ أي محرك أتمتة** — هذا خارج نطاق المرحلة 2 كما في الخطة.

## 17.6 الانحرافات عن مواصفات المرحلة 0

1. **رمز المستخدم طويل الأمد غير مُخزَّن:** تُختم فقط رموز الصفحات لكل أصل؛ «إعادة الربط» تعيد تشغيل OAuth بالكامل (أبسط وأأمن من تخزين رمز مستخدم عام).
2. **`selected` boolean إضافي** بجانب `connectionStatus` (فصل «متصل» عن «مُحدَّد للعمل» — تحسين موثّق بدل تعدد الحالات).
3. **اشتراك إنستغرام = `dashboard_required`:** الاشتراك على مستوى التطبيق يُضاف يدويًا في لوحة المطوّرين؛ التطبيق يسجّل ذلك ولا يستطيع إنشاءه عبر API.
4. **`proofEnabled`** بدل `appsecretProofEnabled` في الاستجابة (حماية من إشارة isSensitiveKey على "secret" — D7 من المرحلة 1).
5. **توقيع غير صالح لا يُخزَّن:** 401 + عدّادات Redis فقط (منع إغراق قاعدة البيانات بهجمات تجريب).
6. **`GET /webhooks/meta` و`GET /meta/oauth/callback` عامّان** (الأول يوثّق التحدي بمقارنة ثابتة الوقت، الثاني يُتحقق بحالة Redis)؛ باقي المسارات محمية جلسة.
7. **تكرار per-entry:** `delivery_hash` = sha256 لـ JSON قياسي (object/entryId/time/field/valueId/verb) — لا يُعاد تخزين الحدث ذاته.
8. **AAD لكل رمز:** `{credential_id}:{asset_id}` يمنع نقل ciphertext بين الأصول.
9. **تدوير المفاتيح بأثر رحمة:** فك بالمفتاح الحالي ثم `APP_ENCRYPTION_KEY_OLD`؛ إعادة-تشفير تحدث عند إعادة حفظ الإعداد/الاتصال (لا reseal تلقائي فوري — مذكور في .env.example).
10. **حد الفيض على مستوى IP** (120/دقيقة → 429) مخزّن في Redis — كافٍ لمالك واحد، وسوسّل موثّق في المخطط للمرحلة 3.
11. **نطاقات Instagram مؤجّلة (D15):** OAuth يطلب الآن 5 نطاقات صفحات فقط؛ `instagram_basic`+`instagram_manage_comments` معزولة في `OAUTH_SCOPES_INSTAGRAM` حتى تحسم Q3 (App Review / Facebook Login for Business) — قرار المالك Q8 أُقرّ لمخرَج واحد لكن التنفيذ الحي أثبت أن مسار Instagram يتطلب خطوة إضافية.

## 17.7 الأسئلة المفتوحة

- **Q15 (غير مانع):** برنامج Reverse Proxy وTLS والمنافذ على خادم المالك — كما في المرحلة 1. *(ملاحظة: يوجد commit `785f742` لتكامل traefik في compose — نفّذه المالك أو أُتحقق منه عند النشر.)*
- **Q3 (قرار المالك — محفوظ كما أقرّه):** عند الحاجة (أ) **التقديم إلى App Review** للمجموعة الدنيا من الصلاحيات هو المسار المعتمد؛ (b) **polling كبديل مؤقت فقط** حيث تسمح به واجهات Meta الرسمية — وملاحظة مهمة: تعليقات إنستغرام عبر polling تحتاج هي أيضًا `instagram_manage_comments` (نفس الصلاحية المؤجّلة)، فالتخفيف لا يزيل الحاجة إلى المسار الرسمي في نهاية المطاف.
- **Q16 (جديد — يمنع إغلاق G2.2):** مسار توصيل الويب هوك الحقيقي: callback المسجَّل في لوحة Meta يجب أن يكون قابلاً لوصول خوادم Meta إليه — إما (أ) النشر على النطاق `https://anychat.egyptcamp.cloud` (compose جاهز مع traefik) وتحديث لوحة المطوّرين بالروابط السحابية، أو (ب) نفق محلي (ngrok أو ما شابه) للتجربة المؤقتة. **localhost لا يصلح للتوصيل الحقيقي.**
- **G2.4:** ينتظر موافقة المالك الصريحة المسبقة على تنفيذ اختبار `--send` على تعليق ومنشور تجريبيين يملكه (مع تذكير: إرسال إنستغرام اليدوي عبر التطبيق لا يُحتسب دليلًا).

## 17.8 تعليمات التشغيل والتحقق + دليل أدلة المالك (لإغلاق G2)

```bash
# تطوير محلي (Postgres 15432 + Redis 6379 — deploy/compose.dev.yml)

# التحقق الكامل (بنفس ترتيب CI)

```

**دليل المالك — الأدلة المطلوبة لإغلاق Gate G2** (التطبيق من نوع Business، وضع التطوير، النطاق `https://anychat.egyptcamp.cloud`):

1. **الإعداد الأساسي:** انسخ App ID وApp Secret في صفحة `/connections` واحفظ؛ اضبط رمز تحقق الويب هوك (نص عشوائي طويل) نفسه في البيئة والصفحة. أضف في لوحة المطوّرين:
   - *Facebook Login → Valid OAuth Redirect URIs*: `https://anychat.egyptcamp.cloud/api/v1/meta/oauth/callback`
   - *Webhooks → Configuration*: callback = `https://anychat.egyptcamp.cloud/api/v1/webhooks/meta` + نفس رمز التحقق.
2. **G2.1:** اضغط «ربط حساب ميتا» → موافقة → تحقق أن الصفحات ظهرت في «الأصول المتصلة». **الدليل:** لقطة شاشة لـ `/connections` (لا تحتاج مموّهة — لا تُعرض رموز أصلًا) + لقطة `GET /me/accounts` من Graph Explorer مموّهة باليد.
3. **G2.2:** من لوحة المطوّرين: «Verify» على الويب هوك ينجح؛ ثم انشر منشورًا على صفحة متصلة وعلّق عليه تعليقًا. **الدليل:** لقطة «تشخيص الويب هوك» تُظهر «آخر حدث وصل» + صفوف في `webhook_delivery` (اطلب السجلات المموّهة أو العدّ). عند الفشل: لقطة رسالة الخطأ (كود/سبب) — أُوثّقها هنا ثم نصعّد Q3.
4. **G2.4:** على نفس التعليق التجريبي: أرسل ردًا خاصًا واحدًا (رسالة خاصة للتعليق) عبر أي وسيلة (واجهة إنستغرام نفسها تكفي للاختبار — المطلوب تجربة صلاحية التطبيق عبر API في موعد لاحق متفق عليه). **بموافقتك الصريحة، منشورك التجريبي فقط، لا إرسال إنتاجي.** الدليل: نجاح/فشل + كود الخطأ.

بعد استلام الأدلة: أُحدّث §17.5 وأُصدر اعتماد Gate G2.
