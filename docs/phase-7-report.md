## 4. القيود التشغيلية المعلومة المعتمدة (Known Operational Limitations)

وفقاً لقرارات المالك المعتمدة في المرحلة 0:
1. **التعليقات القديمة (> 7 أيام):** تمنع سياسة ميتا الصارمة إرسال ردود خاصة لتعليقات مر عليها أكثر من 7 أيام؛ يتعامل النظام معها بالتخطي البرمجي التلقائي وتوثيق السبب.
2. **قيد الرسالة الواحدة (One Message Per Comment):** تسمح ميتا برد خاص واحد فقط لكل تعليق؛ يمنع النظام برمجياً إرسال أي رد خاص ثانٍ لنفس التعليق.
3. **تعليقات المجموعات والبث المباشر (FB Groups & IG Live):** خارج نطاق العمل المعتمد للمشروع (Scope Excluded per Phase 0 Q12).
4. **حساب مالك واحد (Single-Owner):** المنصة مخصصة لمالك وحيد ولا تحتوي على نظام اشتراكات أو تعدد مستأجرين عمداً لتقليل التعقيد البرمجي وتحقيق أقصى استقرار.
