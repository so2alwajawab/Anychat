# تقرير المرحلة 3 — خط أنابيب الأحداث وتطبيع المحتوى (Event Pipeline & Content Ingestion)

**التاريخ:** 2026-10-27
**الحالة:** التنفيذ الآلي مكتمل وجاهز للربط الحي
**النطاق:** تطبيع أحداث الويب هوك، طوابير BullMQ و Redis، استدراك التعليقات (Reconciliation Backfill)، سياسة الخصوصية والاحتفاظ بالبيانات (Retention)، واجهة المحتوى (المنشورات والتعليقات)، وسجلات الإشعارات والتدقيق.

---

## 18.1 الحالة

المرحلة 3 (المحددة في §4.1–§4.4 و§9 من وثيقة المرحلة 0) تم تنفيذها بالكامل:
- موديول جديد `content` في واجهة الـ API (5 مسارات جديدة).
- نموذجان جديدان في قاعدة البيانات: `Post` و `CommentEvent` بفهارس تمنع التكرار نهائياً.
- طابور معالجة خلفي متين مبني على **BullMQ** مع آلية استعادة المهام المتعطلة والتعامل التلقائي مع تكرار الإشعارات `delivery_hash`.
- خدمة تطبيع مستقلة ومُختبرة تدعم أحداث تعليقات فيسبوك (`feed` مع `comment add`) وإنستغرام (`comments`).
- خدمة استدراك ومزامنة حية (Reconciliation) تسحب المنشورات والتعليقات من Graph API لمنع أي فجوات تفوت الويب هوك.
- خدمة حماية الخصوصية (Retention) تطبق تفريغ النصوص والبيانات الشخصية بعد 180 يوماً وحذف الـ payloads الخام بعد 30 يوماً.
- واجهتان كاملتان بالعربية RTL بنسبة 100%: صفحة **المحتوى** (`/content`) لعرض المنشورات والتعليقات وإطلاق المزامنة، وصفحة **السجلات** (`/logs`) لمتابعة إشعارات الويب هوك وتفاصيل الـ payload وسجل التدقيق.

---

## 18.2 ما تم تسليمه

| العنصر | التفاصيل |
|---|---|
| قاعدة البيانات | جدولا `post` (بفهرس فريد `platform, external_id`) و `comment_event` (بفهرس فريد `dedupe_key = platform:externalCommentId:add`). علاقات متسلسلة مع الأصول المتصلة وحذف Cascade عند إزالة الأصل. |
| خط التطبيع | `NormalizationService`: استخراج ذكي وموحد لتعليقات فيسبوك وإنستغرام، مع دعم التمييز بين التعليق الرئيسي والردود المتداخلة (`parentCommentId`) واستخراج معرّفات الناشرين. |
| طوابير الخلفية | `IngestQueueService`: إعداد طابور وعامل BullMQ باسم `ingest` مع 5 مسارات توازي وتراجع أسي 5 ثوانٍ عند الفشل؛ تسجيل تلقائي لمعالجة كل تسليم ويب هوك جديد عبر هوك مباشر غير حاجب في `WebhookService`. |
| الاستدراك والمزامنة | `ReconciliationService`: استدعاءات مهيأة في `GraphClient` لجلب منشورات الصفحات وتعليقاتها وجلب وسائط إنستغرام وتعليقاتها ومطابقتها وتخزينها بصيغة موحدة دون تكرار. |
| الخصوصية والاحتفاظ | `RetentionService`: وظيفة مسح دورية تجعل `text = ''` وتلغي بيانات المعلّق لأي تعليق يتجاوز 180 يوماً مع الحفاظ على المعرّفات للتفادي، وحذف إشعارات الويب هوك الخام بعد 30 يوماً. |
| مسارات API الجديدة | `GET /api/v1/content/posts`، `GET /api/v1/content/comments`، `GET /api/v1/content/comments/:id`، `POST /api/v1/content/sync`، `GET /api/v1/meta/webhooks/deliveries`. |
| الواجهة الأمامية | استبدال الحاويات الفارغة (`Stub`) في صفحة `/content` بصفحة تفاعلية كاملة (تبويبات منشورات وتعليقات، فلاتر أصول ومنصات، وبحث نصي) وصفحة `/logs` (عرض إشعارات الويب هوك وتفاصيل الـ payload وسجلات التدقيق). |
