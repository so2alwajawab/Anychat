# 🚀 AnyChat — منصة أتمتة التعليقات والرسائل الذكية (SaaS)

[![CI Status](https://github.com/anychat/anychat/actions/workflows/ci.yml/badge.svg)](https://github.com/anychat/anychat/actions/workflows/ci.yml)
[![License: Proprietary](https://img.shields.io/badge/License-Proprietary-blue.svg)](LICENSE)
[![RTL Arabic: 100%](https://img.shields.io/badge/RTL%20Arabic-100%25-emerald.svg)](docs/flow-builder.md)

منصة برمجية كخدمة (**SaaS**) متكاملة ومصممة بأحدث التقنيات لأتمتة التفاعل على تعليقات ومنشورات **فيسبوك (Facebook)** و**إنستغرام (Instagram)**، وإرسال ردود عامة متنوعة ورسائل خاصة تفاعلية فورية (Direct Messages & Messenger) بمستوى مماثل ومطور عن **ManyChat** مع دعم كامل للغة العربية واتجاه النص من اليمين لليسار (RTL).

---

## 🌟 ميزات Flow Builder المتقدمة (ManyChat-Grade)

تم تطوير محرر المسارات البصري (**Visual Flow Builder**) ليوفر أحدث وأقوى تقنيات الأتمتة:

1. **⚡ قوالب جاهزة بنقرة واحدة (Pre-built Templates)**:
   - نماذج جاهزة تشمل: استفسارات الأسعار والطلب المباشر، حملات أكواد الخصم والكوبونات، الرد الشامل الذكي، تحويل المتابعين إلى واتساب، وإرسال كتالوج المنتجات.
   - نافذة منبثقة تفاعلية مهيأة بالكامل لمعايير إمكانية الوصول (`FlowTemplatesModal`).

2. **📱 محاكي الموبايل التفاعلي المباشر (Phone Preview Simulator)**:
   - تجربة حية لكيفية ظهور المنشور ورد التعليقات ورسائل الخاص على شاشات الهواتف الذكية.
   - تبديل سلس بين وضعية استعراض المنشور (Post Mode) ووضعية صندوق الرسائل (DM Mode).
   - تجربة كتابة تعليقات حية وفحص استبدال المتغيرات النصية في الوقت الفعلي.

3. **🎲 تنويع صيغ الردود العشوائي (Multi-Reply Anti-Spam)**:
   - إمكانية إضافة عدة صيغ مختلفة لنص الرد العام على التعليق.
   - اختيار عشوائي ذكي لصيغة الرد لكل عميل لحماية الحساب من قيود التكرار والحظر لدى ميتا.

4. **👍 الإعجاب التلقائي بالتعليقات (Auto-Like)**:
   - التفاعل الآلي بالإعجاب على تعليق العميل لرفع معدل الوصول والتفاعل (Engagement Rate) في خوارزميات المنصة.

5. **⛔ استثناء الكلمات السلبية (Negative Keywords)**:
   - مكوّن مخصص (`NegativeKeywordInput`) لمنع تشغيل الأتمتة إذا تضمن التعليق كلمات سلبية أو شكاوى، مع اقتراحات سريعة بنقرة واحدة.

6. **🔘 أزرار تفاعلية داخل الرسائل (Action Buttons)**:
   - مكوّن إدارة الأزرار (`ActionButtonsManager`) لدعم أزرار تحويل المتجر (URL)، محادثات واتساب الفورية (WhatsApp)، أو الاتصال الهاتفي المباشر (Call).

7. **🖼️ تخصيص بيانات المنشور واسم العميل**:
   - حقل رفع صورة أو بوست المنشور (`input[type="file"]`) لمعاينتها فورياً بالمحاكي وتخزينها عبر واجهة البرمجة `/api/post/metadata`.
   - حقل تحديد اسم العميل للمحاكاة والردود المخصصة.

8. **🪄 الترتيب التلقائي للوحة (Auto-Layout)**:
   - خوارزمية ترتيب شجري ذكية (`autoLayoutNodes`) تنظم العقد رأسياً وأفقياً بضغطة زر لمنع أي تداخل بصري.

📖 **للمزيد من الشرح التوضيحي، راجع [دليل محرر المسارات المفصل](docs/flow-builder.md).**

## 🏗️ هيكلية المشروع (Architecture)

المشروع مبني بهيكلية **Monorepo** باستخدام `pnpm workspaces`:

- **`apps/web`**: واجهة المستخدم المبنية بـ **Next.js 16 (App Router)**، و**React 19**، و**Tailwind CSS 4**، و**@xyflow/react**، مع دعم خط **Thmanyah Sans** العربي.
- **`apps/api`**: الخادم الخلفي المبني بـ **NestJS 12**، و**Prisma ORM**، و**PostgreSQL**، و**Redis (BullMQ)**، و**Pino Logger**.
- **`packages/shared`**: حزمة الأنواع المشتركة، التحقق من صحة المسارات (Validators)، وثوابت الواجهة.
- **`deploy`**: ملفات Dockerfile وإعدادات التشغيل والإنتاج.

## 🔒 أمان الربط وإدارة المنصة

- **داشبورد الإدارة (`/admin`)**: مخصصة بالكامل لمالك ومسؤولي المنصة لإدارة المشتركين وربط بيانات تطبيق ميتا (App ID, App Secret, Webhook Verify Token).
- **حماية الأسرار**: تُحفظ بيانات الاعتماد المشفرة على السيرفر ولا تُعرض للعملاء نهائياً.
- **ربط الصفحات للعميل (`/connections`)**: تجربة ربط بنقرة واحدة عبر **Facebook OAuth** الرسمية، حيث يمنح العميل الصلاحية لصفحته دون الحاجة لإنشاء تطبيق مطور أو إدخال أي مفاتيح برمجية.

## 🧪 الاختبارات والجودة

المشروع مغطى باختبارات متكاملة بنسبة 100%:
- **Front-end**: اختبارات الوحدة واختبارات لقطة الشاشة (Snapshots) باستخدام **Vitest** و**React Testing Library**.
- **RTL Arabic Check**: فحص آلي صارم يضمن عدم وجود أي نصوص إنجليزية في الواجهات وتوافر متغير الخط العربي والاتجاه RTL في كافة المسارات.
- **API Tests**: اختبارات التشفير، الصلاحيات، محرك المطابقة، وإدارة الردود ومطابقة الحالات.

```bash
# تشغيل جميع الاختبارات في المشروع
pnpm test

# تشغيل اختبارات واجهة الويب وفحص العربية
pnpm --filter web test

# تشغيل اختبارات الخادم
pnpm --filter api test
```

## 🚀 التشغيل المحلي السريع (Quickstart)

```bash
# 1. تثبيت الاعتماديات
pnpm install

# 2. إنشاء ملف المتغيرات البيئية
cp .env.example .env

# 3. تشغيل خدمات التطوير (قاعدة البيانات والذاكرة المؤقتة)
docker compose -f deploy/compose.dev.yml up -d

# 4. بناء وتشغيل المشروع في وضع التطوير
pnpm dev
```
